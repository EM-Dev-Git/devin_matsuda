# トランスクリプトから議事録作成API 実装計画書

## 1. プロジェクト概要

### 1.1 目的
会議のトランスクリプト（文字起こし）を受け取り、OpenAI GPTを使用して構造化された議事録を自動生成するAPIシステムを構築する。

### 1.2 主要機能
- JWT認証によるセキュアなユーザー認証
- OpenAI APIを使用した高品質な議事録生成
- ユーザー情報のデータベース管理
- 包括的なログ機能
- 環境変数による設定管理

## 2. システム設計

### 2.1 アーキテクチャ概要
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Client App    │───▶│   FastAPI App   │───▶│   OpenAI API    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                              │
                              ▼
                       ┌─────────────────┐
                       │   Database      │
                       │   (SQLite)      │
                       └─────────────────┘
```

### 2.2 技術スタック
- **フレームワーク**: FastAPI
- **認証**: JWT (JSON Web Token)
- **データベース**: SQLite + SQLAlchemy
- **AI**: OpenAI GPT API
- **ログ**: Python logging
- **環境管理**: python-dotenv

## 4. データベース設計

### 4.1 ユーザーテーブル (users)
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    hashed_password VARCHAR(255) NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 4.2 議事録履歴テーブル (meeting_minutes)
```sql
CREATE TABLE meeting_minutes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    original_transcript TEXT NOT NULL,
    generated_minutes TEXT NOT NULL,
    meeting_title VARCHAR(200),
    participants TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users (id)
);
```

## 5. API仕様

### 5.1 認証エンドポイント

#### POST /auth/login
ユーザーログイン

**リクエスト:**
```json
{
    "username": "user@example.com",
    "password": "password123"
}
```

**レスポンス:**
```json
{
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "token_type": "bearer",
    "expires_in": 1800
}
```

#### POST /auth/register
新規ユーザー登録

**リクエスト:**
```json
{
    "username": "newuser",
    "email": "user@example.com",
    "password": "password123"
}
```

### 5.2 議事録生成エンドポイント

#### POST /transcript/generate
トランスクリプトから議事録生成

**ヘッダー:**
```
Authorization: Bearer <access_token>
```

**リクエスト:**
```json
{
    "transcript": "会議の文字起こし内容...",
    "meeting_title": "週次ミーティング",
    "participants": ["田中", "佐藤", "鈴木"]
}
```

**レスポンス:**
```json
{
    "meeting_minutes": "生成された議事録...",
    "generated_at": "2024-01-01T12:00:00Z",
    "status": "success"
}
```
