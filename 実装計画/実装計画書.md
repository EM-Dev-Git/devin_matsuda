# トランスクリプトから議事録作成API 実装計画書

## 1. プロジェクト概要

### 目的
音声トランスクリプトデータを入力として受け取り、OpenAI APIを使用して構造化された議事録を自動生成するWebAPIシステムを構築する。

### 主要機能
- ユーザー認証・認可（JWT）
- トランスクリプト入力受付
- OpenAI APIによる議事録生成
- 生成結果の保存・取得
- ログ管理

## 2. 技術スタック

### バックエンド
- **フレームワーク**: FastAPI
- **認証**: JWT (JSON Web Token)
- **データベース**: SQLite (開発) / PostgreSQL (本番想定)
- **ORM**: SQLAlchemy
- **外部API**: OpenAI API
- **ログ**: Python logging + structlog
- **環境管理**: python-dotenv

## 4. データベース設計

### Usersテーブル
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    hashed_password VARCHAR(255) NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### Transcriptsテーブル
```sql
CREATE TABLE transcripts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    title VARCHAR(200),
    original_transcript TEXT NOT NULL,
    generated_minutes TEXT,
    status VARCHAR(20) DEFAULT 'pending', -- pending, processing, completed, failed
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users (id)
);
```

## 5. API設計

### 認証エンドポイント
```
POST /auth/register          # ユーザー登録
POST /auth/login            # ログイン（JWTトークン発行）
POST /auth/refresh          # トークンリフレッシュ
GET  /auth/me              # 現在のユーザー情報取得
```

### ユーザー管理エンドポイント
```
GET    /users/profile       # プロフィール取得
PUT    /users/profile       # プロフィール更新
DELETE /users/profile       # アカウント削除
```

### トランスクリプト・議事録エンドポイント
```
POST /transcripts                    # トランスクリプト投稿・議事録生成開始
GET  /transcripts                    # ユーザーのトランスクリプト一覧取得
GET  /transcripts/{transcript_id}    # 特定のトランスクリプト・議事録取得
PUT  /transcripts/{transcript_id}    # トランスクリプト更新
DELETE /transcripts/{transcript_id}  # トランスクリプト削除
```

## 6. 実装詳細

### 6.1 認証システム

#### JWT設定
- アルゴリズム: HS256
- アクセストークン有効期限: 30分
- リフレッシュトークン有効期限: 7日
- パスワードハッシュ化: bcrypt

#### セキュリティ要件
- パスワード強度チェック
- レート制限
- CORS設定
- セキュリティヘッダー

### 6.2 OpenAI統合

#### プロンプト設計
```python
MEETING_MINUTES_PROMPT = """
以下のトランスクリプトから議事録を作成してください。

要求事項:
1. 会議の概要
2. 主要な議論ポイント
3. 決定事項
4. アクションアイテム（担当者・期限含む）
5. 次回会議の予定

トランスクリプト:
{transcript}

議事録:
"""
```

#### API呼び出し設定
- モデル: gpt-3.5-turbo または gpt-4
- 最大トークン数: 2000
- 温度: 0.3（一貫性重視）
- エラーハンドリング・リトライ機能

### 6.3 ログ設定

#### ログレベル
- DEBUG: 開発時の詳細情報
- INFO: 一般的な処理情報
- WARNING: 警告事項
- ERROR: エラー情報
- CRITICAL: 重大なエラー

#### ログ出力項目
- タイムスタンプ
- ログレベル
- ユーザーID
- リクエストID
- 処理時間
- エラー詳細
